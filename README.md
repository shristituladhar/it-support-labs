# IT Support Labs

Hands-on IT support labs I've built and documented to practise real service desk and system support work. Each module has a lab, screenshots, the commands I used, and notes on what went wrong and how I fixed it.

## Modules
| # | Module | What's covered |
|---|---|---|
| 1 | [ServiceNow ITSM](module-01-servicenow-itsm/) | Incident tickets, priorities, assignment, SLAs and the full ticket lifecycle in a ServiceNow developer instance |
| 2 | [End User Device Support](module-02-end-user-device-support/) | Windows 11 setup and troubleshooting in a VM: user accounts, apps, drivers, performance and common desktop issues |
| 3 | [Active Directory](module-03-active-directory/) | Domain setup, users, groups, OUs, domain join and Group Policy |
| 4 | [Microsoft 365 & Cloud](module-04-m365-cloud/) | M365 tenant admin: users, licences, mailboxes, Teams and security settings |
| 5 | [Network Support](module-05-network-support/) | IP addressing, DNS, DHCP and connectivity troubleshooting in VMware and Cisco Packet Tracer |
| 6 | [Company File Sharing](module-06-file-sharing/) | File server shares, NTFS permissions, Group Policy drive maps, file recovery with Previous Versions, workgroup sharing, and a NAS with RAID1 |
